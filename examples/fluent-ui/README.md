# Demo

## Description

Handsontable in a React app themed to match [Fluent UI](https://react.fluentui.dev/), so the grid reads as part of the surrounding UI.

## Installation

Install all necessary dependencies with `pnpm install`.

## Development

To start the local development server use `pnpm dev` (`pnpm start` is an alias). You can then visit http://localhost:5173 to view the project — Vite prints the URL on startup and moves to the next free port if 5173 is taken.

Build a production bundle with `pnpm build`, and preview it with `pnpm preview`. The build type-checks first, so a TypeScript error fails it.
