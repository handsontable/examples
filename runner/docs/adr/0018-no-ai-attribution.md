# ADR-0018: No AI attribution in history or code

**Status:** Accepted

## Context
Org policy (the `no-ai-attribution` guidance) forbids AI attribution in the repo.

## Decision
No `Co-Authored-By: Claude`, no "Generated with Claude" footers in commits/PRs, no
`claude/` branches, no AI mentions in file headers. Work lives on the
`runner-live-demos` branch.

## Consequences
- Commits and docs carry no AI attribution.
